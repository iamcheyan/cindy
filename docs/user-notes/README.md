# 用户笔记（user-notes）

**这是使用者视角的实践记录，不是上游治理文档。** `docs/` 根索引（[README.md](../README.md)）收录的是有约束力的产品 / 设计 / 开发规则；
本目录只记录我们自己在真实环境里用 Cindy 的**做法、踩坑和收获**，因此不进根索引，也不对上游行为做约束。

## 写什么

- 环境相关：在某台机器上装 / 配 Cindy 的实际步骤，以及为什么必须那么做
- 集成相关：把外部服务（模型网关、CLI、插件等）接进 Cindy 的过程
- 用法与收获：值得下次复用的命令、字段含义、验证方法
- 上游可改进点：使用中发现的差距，攒着当提 PR 的素材

## 约定

- 一个主题一个文件，文件名用简短英文 slug
- 文件开头写明：记录日期、机器、涉及版本（Cindy / 相关服务）
- 先给结论，再给可复现步骤；步骤要能照抄执行
- 写清**验证方式**和**实际验证结果**——"进程在跑"不等于"功能正常"
- 不写字面密钥 / token / cookie；需要表达时写来源与推导规则，或占位符
- 记录踩坑时写清现象 → 原因 → 规避方法
